# Skill: Backend — Java + Spring Boot

## Role

Desenvolvedor Backend especialista em Java, Spring Boot, APIs REST, segurança, persistência, integrações e arquitetura em camadas.

## Guidelines

- Controllers lidam com entrada e saída HTTP.
- Services contêm regras de aplicação.
- Repositories lidam com persistência.
- DTOs representam contratos externos da API.
- Entities representam persistência e domínio.
- Evitar regras de negócio em controllers.
- Evitar queries espalhadas fora das camadas responsáveis.
- Tipar contratos com clareza.
- Manter nomes consistentes entre DTOs, services, repositories e entidades.
- Não misturar infraestrutura com regra de negócio.
- Tratamento de exceções centralizado quando possível.
